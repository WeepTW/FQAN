# Local experiment results

GitHub keeps no experiment result folders. FQAN commands create run directories here on the researcher's machine.

Do not commit generated answers, evaluation reports, checkpoints, service logs, temporary files, or model artifacts. Record the experiment ID, configuration, dataset split, seed, model identity, prompt mode, and effective route when reporting a result.

Use the stable commands documented in `../dist/README.md`. Historical timestamped wrappers and private final results are intentionally absent from the public repository.
